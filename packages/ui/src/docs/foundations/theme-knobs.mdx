# Theme knobs

A brand is a handful of knobs. Everything else (semantic colours, component radii, type) is derived from them, so a new brand never touches a component.

The knobs are three seed colours (primary, secondary, highlight), the neutral scale, one radius and the font families. They live in `packages/tokens/src/brand/<name>.json`; the table of which tokens each one drives is in the [tokens README](https://github.com/waldowred5/waldow-design/blob/main/packages/tokens/README.md#brand-knobs).

## From one colour to a scale

Each seed colour becomes an 11-step scale (`packages/tokens/palette.ts`). Steps are placed by **OKLCH lightness**, which tracks how light a colour looks across hues, so a given step has about the same contrast whatever colour you pick: step 600 always carries white text, step 400 always carries near-black text. The seed sets the hue and colourfulness. The token build checks every text/background pair against WCAG AA in both modes, and this demo uses the same generator.

## Brand and mode are separate

Light and dark are a **mode** (`data-theme`); a **brand** (`data-brand`) sets the knobs. Any brand works in either mode: switch the toolbar theme while you play. Setting `data-brand` on any element re-derives the tokens for its subtree, which is how this demo themes itself without touching the rest of the page.
