# waldow.design

A small but real design system. This Storybook is the design reference: principles, foundations and every component, in light and dark (use the theme switcher in the toolbar).

- **<DocsLink to="Principles/Overview">Principles</DocsLink>:** short, testable rules with do and don't examples. Link to these in critiques.
- **Foundations:** <DocsLink to="Foundations/Color">colour</DocsLink>, <DocsLink to="Foundations/Typography">typography</DocsLink>, and <DocsLink to="Foundations/Space, radius and elevation">space, radius and elevation</DocsLink>, all rendered live from `@waldow-design/tokens`.
- **Components:** each has a docs page with usage, props and accessibility notes, plus stories for every state.

## How it fits together

1. **Tokens** (`@waldow-design/tokens`): primitive → semantic → component, built to CSS variables with light and dark themes.
2. **Components** (`@waldow-design/ui`): shadcn/ui on Radix, styled only with Tailwind utilities that map to semantic and component tokens ([ADR 001](https://github.com/waldowred5/waldow-design/blob/main/docs/adr/001-shadcn-ui-component-foundation.md)).
3. **Quality gates:** every story is rendered and checked with axe in CI, Chromatic reviews visual changes, tokens fail the build below WCAG AA, and bundles have size budgets.
